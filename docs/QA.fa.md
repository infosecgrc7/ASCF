## پوشش آزمون‌های عمومی

خروجی باید با رابطه، مبنای استدلال، امتیاز و فیلدهای اصلی SCF تأییدشده منطبق باشد. برچسب و شناسهٔ نامعتبر، ستون کم یا اضافه، نقل ساختگی منبع، شاهد AO متعلق به کنترل دیگر، بازبینی حل‌نشده، نبود قیود موروثی، وضعیت متناقض پوشش یا نبود رابطه، زوج تکراری و تغییر نسخه یا هش رد می‌شوند.

آزمون آستانه، ۱ تا ۴ از جمله 4 و 4.0 و رشتهٔ «4.0» را رد می‌کند و 5 و 5.0 و رشتهٔ «5.0» و 10 را می‌پذیرد. مقدار بولی، نامتناهی، خارج از دامنه و اعشاری غیرصحیح رد می‌شود. شمارهٔ بند یکسان در اسناد مختلف تداخل ایجاد نمی‌کند و تکرار نگاشت فرزند مقدمهٔ بند مادر را تکرار نمی‌کند.

آزمون واژگان شامل پذیرش فقط true، تقدم مدخل و نام مستعار افتا، حفظ ابهام، نگهداری اصل فایل، تشخیص تغییر اثر انگشت، جست‌وجوی عنوان کامل و حذف مدخل تعلیق‌شده از تصمیم ترجمه است. بررسی ترجمه، نبود بازبینی، ورودی خالی، شناسه، عدد و نفی را می‌آزماید. تعریف کتاب تکمیلی به‌عنوان مدخل مصوب افتا بازنویسی نمی‌شود.

آزمون Excel فایل واقعی را باز می‌کند و مقدار تغییرکرده، ردیف/ستون پنهان، رنگ ناخوانای متن، پنهان‌سازی با قالب‌بندی شرطی و قالب عددی مخفی را تشخیص می‌دهد. صادرکننده تنظیمات پنهان‌سازی، فیلتر و سبک‌های شرطی الگو را بازنشانی می‌کند. مقادیر نمایشی از دادهٔ مرجع تولید می‌شوند و فرادادهٔ دلخواه ردیف خروجی مسیر دور زدن تأیید نیست.

## آزمون گیت‌هاب و محدودیت‌های بصری

[اجرای موفق پس از اصلاح آستانهٔ ۵ به بالا](https://github.com/infosecgrc7/ASCF/actions/runs/44900846165) هر چهار ترکیب Windows/Ubuntu و Python 3.11/3.13 را پوشش داده است. وضعیت تغییرات جدید را در [Actions](https://github.com/infosecgrc7/ASCF/actions) ببینید.

پیش‌نمایش نمونهٔ Excel با رندرکنندهٔ همراه ساخته و بررسی شد و مقادیر واردشده نیز بررسی شدند؛ فرایند رندرکننده پس از تولید پیش‌نمایش به‌طور غیرعادی پایان یافت. این رندرکننده موتور خروجی ابزار نیست. نمایش بومی Excel، چیدمان دوجهتهٔ فارسی و کیفیت چاپ به‌صورت دستی تأیید نشده‌اند. مقادیر، تنظیم RTL و ساختار ذخیره‌شده بررسی شده‌اند؛ ردیف‌های بلند ممکن است به افزایش ارتفاع نیاز داشته باشند.

بازبینی کامل رونویسی PDF، تأیید مستقل نگاشت واقعی مقررات یا سنجش کمی دقت معنایی انجام نشده است. فیلد تأیید، ثبت ادعای بازبینی است و اثبات احراز‌شدهٔ انجام آن نیست. کد دادهٔ ورودی را بررسی می‌کند و نمی‌تواند صحت رونویسی آن از سند حقوقی را اثبات کند.

منابع کامل دارای مجوز یا خصوصی عمداً منتشر نشده‌اند. ورود و بررسی محلی آن‌ها جداگانه آزموده شده است. انتشار کتاب، ترجمهٔ SCF یا سند مقرراتی به حقوق مربوط به همان منبع وابسته است.

## بازتولید بررسی‌ها

~~~bash
python -m pip install -r requirements.txt
python -m unittest discover -s tests -v
python scripts/audit_release.py
python scripts/build_release.py --out local-data/scf-mapping-toolkit-1.0.0.zip
~~~

بررسی اختیاری دادهٔ خصوصی با scripts/verify_local_data.py و ورودی صریح کاتالوگ، JSONL و manifest قبلی دارای اثر انگشت و پوشهٔ منابع انجام می‌شود. آزمون عمومی گیت‌هاب به این فایل‌ها نیاز ندارد.
