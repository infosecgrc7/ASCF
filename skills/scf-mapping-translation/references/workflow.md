# Workflow and authority

Mapping and translation are independent modes sharing traceability. A translation never establishes a control relationship; a mapping never changes the source duty.

## Mapping

Use original regulatory text, a pinned local SCF workbook, the selected STRM methodology profile and a source inventory. Preserve each document issuer/version/hash and distinct source_id. The code checks exact source fragments against this inventory; it cannot prove that a PDF transcription is correct. Visually resolve ambiguous extraction before recording an approved source review.

Each independent obligation has an original parent ID and a globally unique child ID. Store exact inherited context for every child, even where the parent preamble is shown only once in Excel. Distinguish policy creation, approval, publication, operational implementation, monitoring, record generation, retention and protection when they can pass or fail separately. Do not split mechanically at conjunctions.

Search control descriptions and AOs in multiple relevant domains. Selected AO quotes must belong to the source-column association of the chosen control and match its exact text. An ID-prefix mismatch in the source is reported, preserved and not repaired by inference. Record alternatives for broad or fallback choices. Rank, SCF control weighting and relationship strength are different quantities.

Project acceptance is whole-number strength 5–10 inclusive. Scores 1–4 are rejected, never fallback. If no candidate qualifies, record No Relationship with a reviewed reason and blank strength. Numeric representations 5, 5.0 and "5.0" are equivalent. Booleans, nonfinite values and fractions are rejected. This is a project rule, not a claimed NIST threshold.

The profile pins equality spelling and rationale. Use Functional for the SCF-community profile; a separately documented multi_basis profile permits Functional, Semantic and Syntactic. Neither the validator nor exporter changes an explicit rationale. Equal/Equal To spelling differences must be resolved by selecting the intended source/template profile.

Set-difference notes are explicit for every relationship. Equality has no differences; Subset Of has SCF-only scope; Superset Of has source-only scope; Intersects With has both. Counterexample review is required for equality/subset. Combined coverage reviews name all selected controls and residual clauses. Recorded approval does not itself prove correctness: the reviewer must inspect actual text and all inherited qualifiers.

The exporter derives every display value. Optional ledger output_rows must exactly equal that canonical sequence; arbitrary row edits cannot bypass approved choices. No-match rows have blank SCF/rationale/score cells and a reason. Source IDs, child IDs and physical PDF pages are included in Notes while keeping the ten-column schema. Multiple regulators can reuse the same parent clause number without collision.

## Translation

Authority: matching approved AFTA term/sense, then eligible supplementary definition/equivalent, then reviewed organization or contextual proposal. Full source uploads remain audit-only. No held record can become a runtime result through a duplicate heading, acronym or a raw-Markdown fallback. A separately eligible entry or AFTA term may independently match the same heading.

Keep official Persian equivalents and raw source records unchanged. Search-key normalization is separate. Definitions are preserved quotations with page ranges, coordinates and evidence, not generated summaries or present-day security recommendations. Terms such as authentication, authenticity and authorization require distinct sense checks. Do not apply a cryptographic-key equivalent of compromise indiscriminately to other contexts.

Translation QA catches structural defects and some identifier/number/negation risks. It cannot verify all modalities, quantifiers or omissions. Human or model semantic review must be labelled honestly and cover every unit. Do not fabricate a name, evidence paragraph, reviewer or approval.

## Exclusions from this release

No automatic LLM calls, semantic relationship engine, PDF OCR, legal compliance certification, transitive mapping or automatic ID migration is claimed. Legacy metadata can aid discovery; it does not justify replacing IDs. Inverse/transitive suggestions require a separately tested, direction-aware workflow and do not establish third-party framework compliance.
